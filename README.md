# EECE5510_Project
Magnetic Resonance Image Reconstruction example code in MATLAB.  Requires raw data file (Pfile).   Demonstrates multiple channel image combination using sum-of-squares (P. Roemer et al.), data apodization techniques, homodyne processing (D. Noll et al.), zero padding/interpolation and gradient Non-Linearity correction (Gradwarp). Fred J. Frigo, Marquette University, 25-Oct-2026.
