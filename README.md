# EECE5510_Project
Magnetic Resonance Image Reconstruction example code in MATLAB.  Requires raw data file (Pfile).   Demonstrates multiple channel image combination using sum-of-squares (P. Roemer et al.), data apodization techniques, homodyne processing (D. Noll et al.), zero padding/interpolation and gradient Non-Linearity correction (Gradwarp). The raw data file "dqa_256" is from a 2D axial 24cm FOV head coil scan of a DQA3 phantom.  The raw data file "carboy256" is from a 2D sagital 48cm FOV body coil scan of a phantom containing NiCl. Fred J. Frigo, Marquette University, 25-Oct-2026.
